# ENAcademy

An interactive bilingual English-learning dashboard for daily lessons, vocabulary, grammar, speaking practice, a mini dictionary, and progress tracking.

## Features

- Responsive dashboard with dark and light themes
- English and Persian interface directions
- Interactive lesson flow and grammar quiz
- Searchable dictionary and vocabulary flashcards
- Saved words stored locally in the browser
- Speaking practice using the browser's speech synthesis
- Progress, skill, and activity views

## Run locally

No build step is required. Start any static file server in the project directory:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Deployment

The project can be deployed directly to GitHub Pages, Netlify, Cloudflare Pages, or any static web host.
